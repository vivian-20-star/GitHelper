# Git Tutorial CLI
A simple Python command-line tool created to practice Python fundamentals while explaining basic Git concepts and commands.

It presents an interactive mnu covering what Git is, setup basics, creating a first project, troubleshooting, and extra tools.

## Requirements

- Python 3
- Git

## Download the Project

### Option 1: Clone with Git

1. Open IDE of your choice
2. Navigate to the folder where you want to save the project
3. Clone the repository

```bash
git clone https://github.com/vivian-20-star/GitHelper.git
```
### Option 2: Download as a ZIP File

1. Open the repository page on GitHub.
2. Select **Code**, then **Download ZIP**
3. Extract the ZIP file to a folder on your computer
4. Open a terminal in the extracted project folder. This can be Powershell/Terminal or your choice of IDE.

## Run the Program

Run the tool with:

```bash
python main.py
```

## How to Use It

The tool displays a numbered menu with Git topics from 1-6. Select topic of interest and hit enter to return to the main menu when prompted.

## Topics Included

- Understanding Git
- Setting Up
- Creating Your First Project
- Common Git Errors and Troubleshooting
- Extras and Additional Tools
